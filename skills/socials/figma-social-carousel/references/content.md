# Content decisions

## Choose a useful angle

Before choosing a title, state the reader's problem and the change the post should help them make. A useful list distinguishes choices: what it does, when to use it, and why it belongs. "Best tools" without criteria leaves the reader with another collection of bookmarks.

For an open topic, compare a few angles on usefulness, available evidence, visual clarity, and fit with the audience. Choose or recommend the strongest. Do not restart idea selection when the user already chose the content.

Useful structures include:

- A small toolkit for one task, followed by a chooser.
- A concept the reader often gets wrong, followed by a worked example.
- A comparison with a clear unit, scope, and tradeoff.
- A habit to change, followed by a short repeatable workflow.

## Plan within the budget

Count the cover and CTA before allocating content slides. The ordinary ceiling is ten publishing slides. A nine-slide five-tool roundup can contain a cover, five tools, a chooser, and two requested closing beats. A simpler version can use one close. These are examples, not mandatory templates.

When a supplied list is too long, keep the strongest entries or group only genuinely related items. Never solve a slide-limit problem by making unreadable cards. Notes, captions, music, and source lists belong in separate handoff material.

Write a concrete hook that tells the reader both the subject and the benefit. The next slide should already offer value. Let each body contain one explanation or takeaway; use a few concise lines instead of a paragraph. A tool card can name the tool, a specific use case, and a short request to try.

Remove words that do not add meaning: "powerful," "ultimate," "game-changing," "unlock," and repeated "next-level" claims. Avoid em dashes, stock contrast slogans, repetitive question-and-answer headings, and decorative emoji. Keep the creator's actual voice and requested languages.

## Research and scope

Use official documentation, original research, direct product pages, or clearly scoped source datasets. Record the source URL, access date, and which claim it supports. Replace redirect links with their verified destinations when practical.

For salary or ranking posts, specify the geography, population, time period, currency, compensation type, and statistic. Several countries do not make a worldwide average. Keep seniority consistent; exclude executive roles when the brief calls for ordinary job families. Attribute an external ranking accurately. Label a personal shortlist as editorial choices.

For code, verify syntax and run a small representative example when meaningful. Show useful comments and a visible result. A syntactically valid snippet can still teach the wrong concept.

## Close with a prepared action

Choose the action for the post's purpose:

| Purpose | Useful close |
|---|---|
| Reference | Save this for the next time you need it. |
| Shareable preparation | Send this to someone preparing for the same task. |
| Context-dependent comparison | Does this match your experience in your country? |
| Real resource offer | Comment one keyword for one named, prepared resource. |

If the user asks for a DM offer, write and test the resource first. Keep its description specific and its response short enough for the intended platform. Describe manual delivery honestly. A link pack should contain the actual links. A prompt should fit in one message and be tested before it is offered. Do not imply permission to send it.

Use brand placement only where it belongs in the story. A learning product can be a natural next step after reading an article: write a few questions, answer from memory, and review later. It does not need to appear as an advertisement on every card.

## Platform adaptation

Write separately for the requested platforms. Match the opening, tone, action, media selection, and hashtag use to each one. Verify current limits from official sources when they affect the result; do not encode transient algorithm advice as a permanent rule.

If a platform version omits closing slides, re-export counters and progress marks for its actual length. Do not leave "09" on a seven-slide variant. Captions and alt text must describe the media that will actually be published.
